# JavaScript Learning

This folder contains a collection of JavaScript practice files and mini-examples focused on core language concepts, browser behavior, and common interview-style problems.

## Contents

The repository includes examples covering:

- call, bind, and apply
- closures
- higher-order functions
- async/await
- event bubbling and event delegation
- currying
- debounce and throttling
- deep cloning
- prototype and inheritance
- promises and async patterns
- polyfills
- reduce and array utilities
- DOM interaction and JavaScript fundamentals

## Example files

- `call_bind_apply.html` — demonstrates `call()`, `bind()`, `apply()`, plus `this` behavior and setTimeout usage
- `closures.html` — examples of lexical scope and closure patterns
- `prototype.html` — prototype-based inheritance and object behavior
- `asyncawait.html` — async/await concepts and flow
- `debounce/` — debounce-related examples
- `promise/` — promise creation and handling samples
- `polyfills.html` — custom polyfills for common JavaScript methods
- `reduce.html` — practice with `Array.prototype.reduce()`
- `throttling/` — throttling examples for performance optimization

## How to use

1. Open any `.html` file in a browser.
2. If you are using VS Code, you can also run them with a Live Server extension.
3. Inspect the JavaScript in the file and modify the examples to experiment with behavior.

## Learning goal

This project is intended for hands-on JavaScript learning, especially for understanding:

- how `this` works
- function borrowing and binding
- closure and scope
- asynchronous JavaScript
- front-end event handling
- reusable coding patterns used in interviews and real-world projects

## Notes

Most files are simple standalone examples designed for learning and experimentation, not production-ready apps.
